# 🚀 Sobre o Projeto

Este repositório contém meu **Portfólio Oficial 2025**, criado para apresentar minha evolução como desenvolvedor, meus projetos e minhas habilidades técnicas.

O site foi desenvolvido com:

- 🔥 **HTML5** (estrutura limpa e semântica)  
- 🎨 **CSS3** (animações, grid, flexbox, efeitos neon e gradientes)  
- ⚡ **JavaScript ES6+** (lógica interativa, funções, eventos)  
- 🎞️ **Swiper.js** (navegação suave entre seções)  
- 🛡️ Boas práticas de acessibilidade e segurança  

Esse portfólio representa minha jornada profissional rumo a me tornar **Analista de Segurança da Informação**, enquanto evoluo como Desenvolvedor Frontend.
